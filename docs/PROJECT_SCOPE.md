# Project Scope

## 1. Problem

Operating-system concepts such as process scheduling, memory management, and resource management can be difficult to understand through theory alone. There is a need for a practical platform that connects these concepts with data storage and visualization.

## 2. Proposed Idea

SmartOS Database will be developed as a platform for representing and analyzing operating-system information. The system will connect OS concepts with database storage and application-level communication.

## 3. Objectives

1. Demonstrate important Operating System concepts in a practical way.
2. Represent processes, scheduling information, and system resources.
3. Store structured OS-related data using a DBMS.
4. Provide a simple interface for viewing system information.
5. Apply Computer Networking concepts for communication between components.
6. Create a foundation that can be expanded into a complete working system in later phases.

## 4. Initial Scope

The project is initially focused on:

- Process and CPU scheduling concepts.
- Basic memory/resource information.
- Structured storage of OS-related data.
- Communication between application components.
- A web-based visualization/interface.

## 5. Future Scope

Later phases may include:

- Actual scheduling algorithms.
- Memory-management modules.
- Complete backend and database integration.
- Authentication and user management.
- Advanced system monitoring.
- Testing and deployment.

## 6. Phase 1 Limitation

Phase 1 focuses on the **idea, problem statement, objectives, scope, and proposed architecture**. Full implementation is intentionally reserved for later phases.
